# 本地运行

## 固定内容成品

在仓库根目录运行 `npm run preview`，打开 http://127.0.0.1:3203/ 。浏览器仅加载仓库内的固定数据；YouTube 原片仍由外部网站提供。

重新构建：先在 `product/frontend/` 运行 `npm ci`，再回根目录执行 `npm run build:demo`。构建更新 `demo/site/`，源码、固定数据和预览服务独立于作者本机运行目录。

## 实际产品源码

需要 Python 及 `product/requirements.txt` 中的依赖；建议建立独立虚拟环境。进入 `product/` 后安装依赖，将 `.env.example` 复制为本机 `.env` 并按需要配置已支持的模型连接，再运行 `python start.py`，本机页面地址为 http://127.0.0.1:14854/ 。

运行从新的本机收藏库开始；原始字幕、检索索引、模型权重、历史语料和作者收藏未随源码发布。嵌入/重排模型需由 `cloud_prepare_models.py` 指定的公开模型来源自行准备，并遵守对应许可。新增视频和实际搜索可能消耗模型额度并访问视频平台，字幕是否可获取取决于来源站点与网络。

前端源码重建使用 `product/frontend/` 中的构建脚本。静态演示适配层只支持固定内容，不会为新收藏实时生成问题或导读。

本次对成品做了浏览器核验和代码结构检查，未在全新 Python 环境安装全部机器学习依赖，也未重新验证真实模型与字幕采集链路。
