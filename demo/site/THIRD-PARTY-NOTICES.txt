# ARKx particle field adaptation

Source: [Interactive Particles Music Visualizer](https://github.com/tgcnzn/Interactive-Particles-Music-Visualizer), Tiago Canzian / ARKx, MIT. Fixed commit `afe366de4c10e15f627958d7893ab21da8290ea8`.

Original demo: https://tympanus.net/Tutorials/ParticlesMusicVisualizer/ . The public demo returned a Cloudflare challenge during this task; the original core shaders were replayed locally instead. This is not a claim to have exercised the complete audio demo.

`src/vendor/ark-particles/field.ts` ports `src/js/entities/glsl/vertex.glsl` to CPU TypeScript: the full Ashima simplex noise function, central-difference curl, normal-offset target, and nonlinear distance-to-the-fourth interpolation are reused. The original vertex/fragment files and MIT license are retained here. The `curl.y` repeated positive-epsilon sample is corrected to negative epsilon.

Ashima noise: Ian McEwan / Ashima Arts, MIT, https://github.com/ashima/webgl-noise . License snapshot `6abed1e77ed1e18b181627c35f688eb30c9fe75e` retained separately.

Adaptation: regular spherical rows replace Box/Cylinder geometry; the existing signed drag spring replaces audio/BPM input. Following the user's quieter-motion correction, noise phase/frequency and particle orientation remain fixed at rest, with only 18% of the base curl texture. Dragging reveals stronger folds and differential shear, then returns to that quiet shape. Smooth bounds retain the inner envelope; depth and displacement control point opacity/size in the existing Canvas renderer. No bloom, soundtrack, GSAP, additional renderer, or upstream interface is included. Existing wire-shell topology, orbit motion and reading pause are preserved.

Later user-requested dot-size treatment: a broad size crest travels around the fixed spherical surface every 18 seconds. Only radii change automatically (0.24–1.65 CSS px); geometry and opacity retain the quiet behavior. It uses the existing reading clock, so hover/focus, manual pause and reduced motion freeze the size cycle too. This size treatment is a local adaptation based on the user's dot-sphere image, not an upstream ARKx feature.

# ClipCompass vector wordmark — Instrument Serif

The 2026-10-29 brand refinement uses the actual **Instrument Serif** type outlines:
italic `Clip`, regular `Compass`, with an optically adjusted join and 32-unit type size.
This is typesetting and outline adaptation, not a claim to newly designed letterforms.

- Project: https://github.com/Instrument/instrument-serif
- Official specimen: https://fonts.google.com/specimen/Instrument+Serif
- Retrieved source: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- Original files retained here: `InstrumentSerif-Regular.ttf`, `InstrumentSerif-Italic.ttf`, `OFL.txt`.
- Copyright 2022 The Instrument Serif Project Authors. SIL Open Font License 1.1;
  the complete unmodified license is retained and copied into both local builds.
- Downloaded 2026-10-29; SHA-256 of the original files is recorded in `source-hashes.json`.

`BrandMark.tsx` and `frontend/src/assets/brand/clipcompass.svg` contain actual paths
generated from these two fonts. No font request, text fallback, raster image or
conversion library is needed at runtime. The outer mark preserves Lucide's circle
and exact needle geometry, adapted into an engraved compass with a longer needle,
four short ticks and one weighted arc. The later color-only refinement keeps all
outlines and uses a blue ring, ochre needle and navy lettering. Lucide ISC / Feather MIT
notices remain under `lucide-compass/`.

Reproduction script and OpenType.js 1.3.4 (MIT) conversion tool are process materials
in `work/brand-vector-20261029/`; they are not frontend dependencies or deployed code.
The standalone SVG is also copied to `library/static/brand/clipcompass.svg`.
The parent's accessible link name remains `ClipCompass 首页`; decorative inline SVG
is hidden from assistive technology to avoid duplicate announcements.

# User-authorized Kimi knowledge atlas adaptation

- Retrieved 2026-10-27: `reference.html`, `/assets/index-CdQC-nPo.js` (`reference.js`), `/assets/index-Bnut3962.css` (`reference.css`). Original responses retained here for traceability.
- The original application did not declare a public reuse license. The user explicitly authorized reuse in this conversation: **“可以直接复用这页代码”**. This is the permission basis for the local adaptation; it is not an assertion that the application is MIT or that unrestricted redistribution has been granted.
- Embedded Three.js revision 170 is MIT. Original notice retained in `THREE-LICENSE.txt`, verified from https://github.com/mrdoob/three.js/blob/r170/LICENSE.

## Actual code reused

`src/vendor/kimi-atlas/runtime.js` contains the original Three.js runtime and the original `GR`, `FR`, `HR` graph implementation. The camera, force layout, node/edge rendering, label-placement candidates, mouse drag, zoom, rotation, filtering, path traversal and disposal come directly from the reference application.

`src/vendor/kimi-atlas/AtlasShell.jsx` retains the original React shell, SVG icons, cosmos background, sidebar, heading, graph controls, theme switch, lists and native dialogs. It uses the project's existing React rather than a second bundled copy. `atlas-source.css` is the original stylesheet with document resets scoped to atlas mode and remote font declarations removed.

Local adaptations: existing question IDs/text/data, explicit editorial exploration relations, Chinese multiline label bounds and collision handling, selected-label priority, topic focus, browser history, learning panel using existing context/clip components, bottom ask bridge to the existing local search, reading dialog and source availability. The original sample physics data, uploads/AI import, SDK/analytics and sample source contents are not used at runtime. Original exported bundles are archived, not loaded by the product page.

The bottom composer adapts **Prompt Kit `prompt-input-actions.tsx`**, MIT, commit `5a9496635cc0e1bf7679fe2a9e35d9b36b99c08a`: https://github.com/ibelick/prompt-kit/tree/5a9496635cc0e1bf7679fe2a9e35d9b36b99c08a . Its input/action row/circular submit composition is retained; native controls replace wrappers for the existing application. License: `../prompt-kit/LICENSE.md`. The inspected upstream file is retained alongside the license in `../prompt-kit/prompt-input-actions.tsx`.

Runtime evidence and boundaries: `docs/knowledge-atlas-20261027.md`. Desktop only. No content or model output was regenerated for this integration.

2026-10-27 follow-up: the retained `GR / FR / HR` code now displays each complete question and its topic marker as one node. Edges use the displayed node centre, with the original Three camera and line rendering; actual text height drives the retained collision placement, and selection prioritizes the current question plus its direct neighbors. This adapts the authorized source rather than replacing the graph with a new component. The reference files and original notices are unchanged. Desktop evidence and limitations: `docs/atlas-node-text-20261027.md`.

and logo. The existing Kimi layout is retained; this is only a color/surface layer.

# Three.js orbit field adaptations

Upstream: https://github.com/mrdoob/three.js, fixed tag **r170**, MIT.
Original files are retained unchanged alongside the complete `LICENSE`:

- `webgpu_tsl_compute_attractors_particles.html`
  https://github.com/mrdoob/three.js/blob/r170/examples/webgpu_tsl_compute_attractors_particles.html
- `webgl_buffergeometry_drawrange.html`
  https://github.com/mrdoob/three.js/blob/r170/examples/webgl_buffergeometry_drawrange.html

Actual adapted code: `frontend/src/vendor/three-examples/orbit-field.ts`.

The attractor example's force loop is ported from GPU TSL to CPU Vector3:
direction and inverse-square attraction, plus the cross-product spinning force.
ClipCompass supplies real moving orbit anchors, softens close distances and
subtracts centre acceleration. Its wire core bounds displacement and eases toward
the result. The upstream particle integrator, GPU buffers, colour/GUI, scene and
box wrapping are not copied. This is a visual tidal response, not a calibrated
gravity simulation.

The drawrange example's pair-distance test, per-node connection budget and
distance opacity are reused. ClipCompass excludes permanent shell edges and fades
auxiliary connections over time. The original sphere composition reuses the
installed Three IcosahedronGeometry and EdgesGeometry.

The 2026-10-29 topology interaction additionally imports the installed r170
`three/examples/jsm/math/ConvexHull.js` (same MIT license) directly. Its QuickHull
implementation computes triangular neighbours on normalized shell directions;
ClipCompass displays those edges on the deformed vertices and fades edge changes.
This keeps shallow inward ripples from removing shell nodes. Drag input drives
local differential surface flow rather than a rigid rotation of the core. This
is dynamic visual graph connectivity, not a physical fluid or material solver.

Both current official demos were opened and animated in Chromium on 2026-10-29;
the copied sources are the pinned r170 versions. No external request is made by
the production effect. The build distributes this record and the full MIT notice.

# ARKx particle field adaptation

Source: [Interactive Particles Music Visualizer](https://github.com/tgcnzn/Interactive-Particles-Music-Visualizer), Tiago Canzian / ARKx, MIT. Fixed commit `afe366de4c10e15f627958d7893ab21da8290ea8`.

Original demo: https://tympanus.net/Tutorials/ParticlesMusicVisualizer/ . The public demo returned a Cloudflare challenge during this task; the original core shaders were replayed locally instead. This is not a claim to have exercised the complete audio demo.

`src/vendor/ark-particles/field.ts` ports `src/js/entities/glsl/vertex.glsl` to CPU TypeScript: the full Ashima simplex noise function, central-difference curl, normal-offset target, and nonlinear distance-to-the-fourth interpolation are reused. The original vertex/fragment files and MIT license are retained here. The `curl.y` repeated positive-epsilon sample is corrected to negative epsilon.

Ashima noise: Ian McEwan / Ashima Arts, MIT, https://github.com/ashima/webgl-noise . License snapshot `6abed1e77ed1e18b181627c35f688eb30c9fe75e` retained separately.

Adaptation: regular spherical rows replace Box/Cylinder geometry; the existing signed drag spring replaces audio/BPM input. Following the user's quieter-motion correction, noise phase/frequency and particle orientation remain fixed at rest, with only 18% of the base curl texture. Dragging reveals stronger folds and differential shear, then returns to that quiet shape. Smooth bounds retain the inner envelope; depth and displacement control point opacity/size in the existing Canvas renderer. No bloom, soundtrack, GSAP, additional renderer, or upstream interface is included. Existing wire-shell topology, orbit motion and reading pause are preserved.

Later user-requested dot-size treatment: a broad size crest travels around the fixed spherical surface every 18 seconds. Only radii change automatically (0.24–1.65 CSS px); geometry and opacity retain the quiet behavior. It uses the existing reading clock, so hover/focus, manual pause and reduced motion freeze the size cycle too. This size treatment is a local adaptation based on the user's dot-sphere image, not an upstream ARKx feature.

# ClipCompass vector wordmark — Instrument Serif

The 2026-10-29 brand refinement uses the actual **Instrument Serif** type outlines:
italic `Clip`, regular `Compass`, with an optically adjusted join and 32-unit type size.
This is typesetting and outline adaptation, not a claim to newly designed letterforms.

- Project: https://github.com/Instrument/instrument-serif
- Official specimen: https://fonts.google.com/specimen/Instrument+Serif
- Retrieved source: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- Original files retained here: `InstrumentSerif-Regular.ttf`, `InstrumentSerif-Italic.ttf`, `OFL.txt`.
- Copyright 2022 The Instrument Serif Project Authors. SIL Open Font License 1.1;
  the complete unmodified license is retained and copied into both local builds.
- Downloaded 2026-10-29; SHA-256 of the original files is recorded in `source-hashes.json`.

`BrandMark.tsx` and `frontend/src/assets/brand/clipcompass.svg` contain actual paths
generated from these two fonts. No font request, text fallback, raster image or
conversion library is needed at runtime. The outer mark preserves Lucide's circle
and exact needle geometry, adapted into an engraved compass with a longer needle,
four short ticks and one weighted arc. The later color-only refinement keeps all
outlines and uses a blue ring, ochre needle and navy lettering. Lucide ISC / Feather MIT
notices remain under `lucide-compass/`.

in `work/brand-vector-20261029/`; they are not frontend dependencies or deployed code.

The parent's accessible link name remains `ClipCompass 首页`; decorative inline SVG
is hidden from assistive technology to avoid duplicate announcements.

# Three.js orbit field adaptations

Upstream: https://github.com/mrdoob/three.js, fixed tag **r170**, MIT.
Original files are retained unchanged alongside the complete `LICENSE`:

- `webgpu_tsl_compute_attractors_particles.html`
  https://github.com/mrdoob/three.js/blob/r170/examples/webgpu_tsl_compute_attractors_particles.html
- `webgl_buffergeometry_drawrange.html`
  https://github.com/mrdoob/three.js/blob/r170/examples/webgl_buffergeometry_drawrange.html

Actual adapted code: `frontend/src/vendor/three-examples/orbit-field.ts`.

The attractor example's force loop is ported from GPU TSL to CPU Vector3:
direction and inverse-square attraction, plus the cross-product spinning force.
ClipCompass supplies real moving orbit anchors, softens close distances and
subtracts centre acceleration. Its wire core bounds displacement and eases toward
the result. The upstream particle integrator, GPU buffers, colour/GUI, scene and
box wrapping are not copied. This is a visual tidal response, not a calibrated
gravity simulation.

The drawrange example's pair-distance test, per-node connection budget and
distance opacity are reused. ClipCompass excludes permanent shell edges and fades
auxiliary connections over time. The original sphere composition reuses the
installed Three IcosahedronGeometry and EdgesGeometry.

The 2026-10-29 topology interaction additionally imports the installed r170
`three/examples/jsm/math/ConvexHull.js` (same MIT license) directly. Its QuickHull
implementation computes triangular neighbours on normalized shell directions;
ClipCompass displays those edges on the deformed vertices and fades edge changes.
This keeps shallow inward ripples from removing shell nodes. Drag input drives
local differential surface flow rather than a rigid rotation of the core. This
is dynamic visual graph connectivity, not a physical fluid or material solver.

Both current official demos were opened and animated in Chromium on 2026-10-29;
the copied sources are the pinned r170 versions. No external request is made by
the production effect. The build distributes this record and the full MIT notice.

# ClipCompass vector wordmark — Instrument Serif

The 2026-10-29 brand refinement uses the actual **Instrument Serif** type outlines:
italic `Clip`, regular `Compass`, with an optically adjusted join and 32-unit type size.
This is typesetting and outline adaptation, not a claim to newly designed letterforms.

- Project: https://github.com/Instrument/instrument-serif
- Official specimen: https://fonts.google.com/specimen/Instrument+Serif
- Retrieved source: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- Original files retained here: `InstrumentSerif-Regular.ttf`, `InstrumentSerif-Italic.ttf`, `OFL.txt`.
- Copyright 2022 The Instrument Serif Project Authors. SIL Open Font License 1.1;
  the complete unmodified license is retained and copied into both local builds.
- Downloaded 2026-10-29; SHA-256 of the original files is recorded in `source-hashes.json`.

`BrandMark.tsx` and `frontend/src/assets/brand/clipcompass.svg` contain actual paths
generated from these two fonts. No font request, text fallback, raster image or
conversion library is needed at runtime. The outer mark preserves Lucide's circle
and exact needle geometry, adapted into an engraved compass with a longer needle,
four short ticks and one weighted arc. The later color-only refinement keeps all
outlines and uses a blue ring, ochre needle and navy lettering. Lucide ISC / Feather MIT
notices remain under `lucide-compass/`.

Reproduction script and OpenType.js 1.3.4 (MIT) conversion tool are process materials
in `work/brand-vector-20261029/`; they are not frontend dependencies or deployed code.
The standalone SVG is also copied to `library/static/brand/clipcompass.svg`.
The parent's accessible link name remains `ClipCompass 首页`; decorative inline SVG
is hidden from assistive technology to avoid duplicate announcements.
